# Frontend Builder

Use this skill when a task involves product UI, dashboards, chatbot interfaces, review queues, onboarding flows, landing pages, or frontend implementation plans.

Return practical outputs:

- user journeys and screens,
- component breakdown,
- important states and edge cases,
- accessibility requirements,
- API/data dependencies,
- implementation sequence and risks.

Prefer implementation-ready structure over visual fluff.
