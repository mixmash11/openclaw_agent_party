# Party Mode Meeting

Party Mode Prompt is an OpenClaw skill for producing a prompt-only sequential multi-agent roundtable transcript.

Use it with:

```text
/skill party_prompt <topic>
```

The skill asks the model to select 3-4 role-based participants, invite them one at a time, allow short reactions or passes, and return a final transcript with a brief wrap-up.

This skill has no external dependencies, credentials, scripts, or tools. It is instruction-only.
