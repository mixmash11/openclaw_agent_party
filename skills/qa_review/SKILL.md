# QA Review

Use this skill when a task needs test planning, acceptance criteria, regression risk, edge cases, release readiness, or quality gates.

Return practical outputs:

- acceptance criteria,
- happy path and failure path tests,
- regression and integration risks,
- manual QA checklist,
- automated test recommendations,
- release blockers and monitoring needs.

Focus on what would prove the feature is ready to ship.
