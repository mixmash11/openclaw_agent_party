# Security Risk

Use this skill when a task involves regulated data, sensitive documents, identity information, authorization, audit logs, privacy, abuse cases, or operational risk.

Return practical outputs:

- sensitive data inventory,
- threat model and abuse cases,
- access control and least-privilege recommendations,
- logging and monitoring requirements,
- privacy and retention concerns,
- risk mitigations and launch blockers.

Separate must-have controls from later hardening.
